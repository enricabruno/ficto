# FiCT-O

**FiCT-O** (Fictional Character Ontology) is a formal model designed to integrate various existing ontologies used in the field of Cultural Heritage, including LRMoo, FRBRoo, RDA, CIDOC-CRM, DUL, PROV-O, and SKOS. FiCT-O aims to represent the evolution of fictional characters over time, along with other narratological aspects within literary texts.

A knowledge base has been created to store the descriptions of five case studies drawn from detective fiction:

1. *A Study in Scarlet* by Arthur Conan Doyle  
2. *The Hound of the Baskervilles* by Arthur Conan Doyle  
3. *The Final Problem* by Arthur Conan Doyle  
4. *La verità sul caso D.* by Fruttero & Lucentini  
5. *Le Loup chantant de Forest Gate* by OuLiPoPo (Ouvroir de Littérature Policière Potentielle)
