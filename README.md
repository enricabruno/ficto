# FiCtO
fiCtO (Fictional Character Ontology) is a formal model designed to integrate various existing ontologies used in the field of cultural heritage (i.e. LRMoo, FRBRoo, RDA, CIDOC-CRM, DUL, PROV-O). FiCtO aims to represent the evolving of fictional characters during time together with other narratological aspects within literary texts. 
A knowledge base (BAFiCtO) was created to stores the description of five cases study taken from the detective fiction: three Arthur Conan Doyle's texts, one text of Fruttero&Lucentini and one text of OuLiPoPo.
